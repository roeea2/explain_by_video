מה מקבלים

עמוד אינטרנט מוכן

נגן עם פרקים, כתוביות, מהירות ניגון, מסך מלא, ותמליל שאפשר לקפוץ ממנו לכל משפט. עובד גם בלי אינטרנט ובכל אחסון סטטי.

קריינות שלא נשמעת כמו רובוט

קול נוירוני (Gemini TTS) בעברית טבעית, בטון של מורה. כל קטע מתומלל בחזרה ומושווה לטקסט, וקטע לא תקין מוקלט מחדש.

MP4 וכתוביות

וידאו 1080p עם פס כתוביות וקובץ SRT, לוואטסאפ, ליוטיוב או למצגת. הייצוא מצייר כל פריים בדיוק כמו הנגן.

עברית ונוסחאות

טקסט מימין לשמאל עם מספרים, יחידות ונוסחאות בסדר הנכון: 9.8 m/s², T = 2π√(L/g), אינדקסים וחזקות.

מודל מול מציאות

בנושאי מדע, פרק סיום שמפרט כל הנחה של המודל, מה המעבדה האמיתית מוסיפה, ואיך רואים את זה בנתונים.

שינויים זולים

כל סצנה היא קוד: משנים מספר או משפט ומקבלים סרטון מעודכן. רק משפט קריינות שהשתנה מוקלט מחדש.

איך זה עובד

Claude עובד לפי סדר קבוע, ובודק את העבודה שלו לפני שהוא מוסר.

  1. שאלותנושא וחומר, קהל, שפה, אורך, קריינות, ומה למסור.
  2. תסריט קודםפרקים, כתוביות וטקסט לקריין. אתם מאשרים לפני שמתחילים לצייר.
  3. ציור בקודכל סצנה היא פונקציה של הזמן, עם ערכת עזרים: טקסט, תוויות, חצים, נוסחאות, גרפים, טבלאות ומכשירי מעבדה.
  4. בדיקה אוטומטיתשגיאות, טקסט שיוצא מהמסגרת, טקסט חופף, גלישה בטלפון. ואז Claude מסתכל על גיליונות של כל הפריימים.
  5. קריינותהקלטה, תמלול בחזרה והשוואה לטקסט. קטע לא תקין מוקלט שוב.
  6. תזמוןהקול הוא השעון. הבודק מציע תזמון חדש כך ששום אנימציה לא מואטת.
  7. מסירהעמוד אינטרנט, MP4 עם כתוביות, ואם תבקשו, העלאה ל-Vercel אחרי בדיקת חשיפה.

התקנה

הסקיל מותקן בתוך תיקיית הפרויקט, לא גלובלית. מהטרמינל, מתוך תיקיית הפרויקט:

mkdir -p .claude/skills && curl -fsSL -o aec.zip https://animation-explainer-creator.vercel.app/animation-explainer-creator.zip && unzip -q aec.zip -d .claude/skills && rm aec.zip

או עם git, ישר מהמאגר ב-GitHub:

git clone --depth 1 https://github.com/roeea2/explain_by_video.git aec-src && mkdir -p .claude/skills && cp -R aec-src/skill/animation-explainer-creator .claude/skills/ && rm -rf aec-src

או להדביק ב-Claude Code, מתוך תיקיית הפרויקט:

https://animation-explainer-creator.vercel.app/animation-explainer-creator.zip

In English

Animation Explainer Creator is a project-scoped Claude Code skill that makes narrated explainer films drawn in code on an HTML canvas, with no video model and no footage. Claude writes the script for your approval, draws every scene as a function of time, checks each frame for errors, text outside the frame and overlapping text, records the narration with Gemini TTS and verifies every clip by transcribing it back, and lets the picture wait for the voice. You get a web page with chapters, captions and a clickable transcript, and an MP4 with subtitles. Hebrew and other right-to-left languages are first-class.
